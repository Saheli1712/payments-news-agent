What it does

Built for fast scans, smarter summaries, and follow-up questions.

RSS-first ingestion

Reads public ET feeds instead of scraping page content, with robots.txt checks and rate limiting.

Clean filtering

Retains only payments-focused stories, removes duplicates, and sorts newest updates first.

Claude summaries

Creates a digest of the latest developments with structured AI-generated summaries and links.

Ask-the-agent mode

Query recent payments news and ask follow-up questions with a LangChain-powered research flow.

Quick start

Run locally with a few commands.

python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m payments_news fetch --hours 24 --limit 10
